# TestGit
这是一个练习 Git 基本使用的仓库，同时包含多个 Vibe Coding 实践项目，存放少量的笔记。

## 项目概览

### Vibe Coding 实践项目

#### 1. 每日一句（one-word）
- **技术栈**：Vue.js + Vite
- **功能**：每日为用户推荐一句经典古诗词名句，简约中国风设计（水墨底色、书法字体、留白意境），支持手动刷新
- **目录**：`vibe-coding-practice/one-word/`

#### 2. 待办事项（reminder）
- **技术栈**：纯原生 HTML/CSS/JS（单文件）
- **功能**：待办事项管理应用，支持添加、完成、删除、编辑任务，玻璃拟态风格，柔和天空蓝主题
- **目录**：`vibe-coding-practice/reminder/`

#### 3. 图片压缩工具（zip）
- **技术栈**：Flask + Vanilla HTML/CSS/JS
- **功能**：图片上传、压缩、对比与下载，支持质量调节、格式转换、批量处理
- **目录**：`vibe-coding-practice/zip/`

## 自动化脚本

### 按键录制回放工具（automation）
按鍵精灵风格的自动化脚本工具，支持录制鼠标键盘操作、自动生成 Python 脚本并回放。

**功能**：
- 录制鼠标移动、点击、滚轮及键盘敲击，精确到毫秒级
- 将录制数据转换为可独立运行的 Python 脚本
- 按原始时间间隔精确复现所有操作，支持倍速回放

详细使用说明请查阅：[vibe-coding-practice/automation/README.md](./vibe-coding-practice/automation/README.md)
