# 待办事项应用 - 设计规格

## 1. 概念与愿景

一款清新淡雅的待办事项应用，以柔和的天空蓝为主色调，营造宁静专注的工作氛围。采用玻璃拟态(Glassmorphism)风格，增添现代感与层次感。整体感觉：清晨宁静、整洁有序、专注高效。

## 2. 设计语言

### 美学方向
- 玻璃拟态 + 柔和渐变
- 清新淡雅的天空蓝主题
- 大量留白，轻盈通透

### 色彩方案
```css
--primary: #3B82F6;          /* 明亮蓝 - 主按钮 */
--primary-dark: #2563EB;     /* 深蓝 - 悬停状态 */
--primary-light: #93C5FD;    /* 浅蓝 - 高亮 */
--bg-gradient-start: #E0F2FE; /* 天蓝渐变起点 */
--bg-gradient-end: #F0F9FF;  /* 极浅蓝渐变终点 */
--surface: rgba(255,255,255,0.7); /* 玻璃表面 */
--text-primary: #1E3A5F;     /* 深蓝文字 */
--text-secondary: #64748B;   /* 灰蓝次要文字 */
--success: #10B981;          /* 完成状态绿 */
--danger: #EF4444;           /* 删除红 */
--shadow: rgba(59, 130, 246, 0.15); /* 蓝色阴影 */
```

### 字体
- 标题: "Nunito", sans-serif (圆润可爱)
- 正文: "Nunito Sans", sans-serif (清晰易读)

### 空间系统
- 基础单位: 8px
- 圆角: 12px (中), 16px (大), 24px (卡片)
- 阴影: 0 8px 32px rgba(59, 130, 246, 0.15)

### 动效哲学
- 任务添加: 从上方滑入 + 淡入 (300ms ease-out)
- 任务删除: 向左滑出 + 淡出 (250ms ease-in)
- 复选框: 弹性缩放 + 颜色渐变 (200ms)
- 按钮悬停: 轻微上浮 + 阴影加深 (150ms)

## 3. 布局与结构

### 页面结构
- 背景: 柔和蓝渐变 + 淡云纹理
- 居中卡片容器 (max-width: 520px)
- 顶部: 标题 + 统计概览
- 中部: 输入区域 (玻璃拟态)
- 下部: 任务列表

### 响应式
- Desktop: 520px 宽度居中
- Tablet: 90% 宽度
- Mobile: 全宽减去 24px 边距

## 4. 功能与交互

### 核心功能
1. **添加任务**: 输入框 + 优先级选择 + 添加按钮，回车或点击均可添加
2. **完成任务**: 点击复选框切换状态，已完成显示删除线
3. **删除任务**: 点击删除按钮移除，带确认动画
4. **统计显示**: 实时显示"X 项待办 / Y 项已完成"
5. **编辑任务**: 点击编辑按钮修改内容和优先级
6. **清空全部**: 弹出确认对话框，确认后删除所有任务
7. **优先级排序**: 高优先级任务显示在前面，低优先级在底部

### 交互细节
- 输入框聚焦: 边框高亮 + 阴影扩散
- 空输入提交: 输入框抖动提示
- 任务悬停: 背景轻微变色
- 删除按钮悬停: 变红色

### 数据持久化
- LocalStorage key: "todo-app-tasks"
- 格式: JSON数组 [{id, text, completed, createdAt}]

## 5. 组件清单

### 输入组件
- 玻璃拟态背景 (backdrop-filter: blur)
- 圆角输入框 (border-radius: 12px)
- 添加按钮 (primary蓝色，圆角)

### 任务项
- 左侧复选框 (自定义蓝色样式)
- 任务文字 (completed时添加删除线)
- 右侧删除按钮 (hover时变红)
- 悬停状态: 背景微变

### 统计栏
- 玻璃拟态小卡片
- 两列布局: 待办数 + 已完成数
- 图标装饰

## 6. 技术方案

- 单文件 HTML (内嵌 CSS + JS)
- 纯原生 JavaScript
- CSS 变量管理主题
- LocalStorage 持久化
- 无外部依赖 (仅 Google Fonts CDN)
