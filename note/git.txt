Git 的使用
**本地分支

基础：
Git init
Git add .
Git commit -m
Git branch -f
Git merge
Git rebase

在提交树上移动：
HEAD: git checkout -b -f [ref]
(其中[ref]可以是某个历史节点的哈希值，
也可以是分支后面加上^~)
^[num]: HEAD移动到第num个父节点
~[num]: 回退num个节点 
(引用支持临链式操作)
Git reset
Git revert

自由修改提交树：
Git cherry-pick: 后面的节点按顺序提交到HEAD节点上
Git rebase -i 

Git tag:永远指向一个节点的标识
Git describe [ref]: 查找距离ref最近的tag
Git config
Git log:查看git的节点提交信息
Git status:显示工作区和暂存区的状态

**远程仓库

Git clone
Git fetch
Git pull
Git push
Git remote
