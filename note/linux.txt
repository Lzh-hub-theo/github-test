Shell 常用通配符：
字符			含义
*				匹配 0 或多个字符
?				匹配任意一个字符
[list]				匹配 list 中的任意单一字符
[^list]			匹配 除 list 中的任意单一字符以外的字符
[c1-c2]			匹配 c1-c2 中的任意单一字符 如：[0-9][a-z]
{string1,string2,...}	匹配 string1 或 string2 (或更多)其一字符串
{c1..c2}			匹配 c1-c2 中全部字符 如{1..10}

linux特点与优势：
开源免费，权限管理严格，支持多人同时操作，高效处理多个任务。

Linux shell 基础操作：
[Ctrl+c]	 中止
[Ctrl+a]	 光标到命令行头
[Ctrl+e]	 光标到命令行尾
[Ctrl+k]	 从光标处删到行末
[Alt+Backspace] 	向前删除一个单词
[Shift+PgUp] 	将终端显示向上滚动
[Shift+PgDn] 	将终端显示向下滚动

环境变量
Declare 	创建指定类型的变量
[var]=[value]	变量赋值(无空格)
set	显示当前 Shell 所有变量
env	显示与当前用户相关的环境变量，还可以让命令在指定环境中运行。
export	显示从 Shell 中导出成环境变量的变量，也能通过它将自定义变量导出为环境变量。
Unset [var]	删除变量

变量修改
变量设置方式	说明
${变量名#匹配字串}	从头向后开始匹配，删除符合匹配字串的最短数据
${变量名##匹配字串}	从头向后开始匹配，删除符合匹配字串的最长数据
${变量名%匹配字串}	从尾向前开始匹配，删除符合匹配字串的最短数据
${变量名%%匹配字串}	从尾向前开始匹配，删除符合匹配字串的最长数据
${变量名/旧的字串/新的字串}	将符合旧字串的第一个字串替换为新的字串
${变量名//旧的字串/新的字串}	将符合旧字串的全部字串替换为新的字串

用户及文件权限管理

Sudo useradd <user>	只添加用户
Sudo - <user>	切换用户与环境变量
Groups <user>	查看用户的用户组
Sudo usermod -aG <group> <user> 	为用户添加用户组
sudo deluser lilei --remove-home	删除用户以及用户的工作目录
Ls -l	查看文件权限
sudo chown <user> <file>	将文件所有者改为该用户
Chmod g(group) o(others) u(user)	修改文件权限
